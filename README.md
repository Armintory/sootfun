# ربات تلگرام SootFun 🎵

ربات صوت فان برای جستجو و اشتراک‌گذاری ویس‌های کوتاه و جذاب در تلگرام

## ویژگی‌های اصلی

- 🔍 جستجوی فازی (Fuzzy Search) با تشخیص خطای تایپی
- 🤖 حالت Inline Bot برای استفاده در گروه‌ها
- 🎬 تبدیل ویدیو به ویس با قابلیت برش
- 📱 رابط کاربری شیشه‌ای و جذاب
- ⚙️ پنل مدیریت اختصاصی برای ادمین
- 📊 آمارگیری و گزارش‌دهی

## نصب و راه‌اندازی

### پیش‌نیازها

```bash
# نصب پکیج‌های مورد نیاز
pip install -r requirements.txt

# نصب FFmpeg برای پردازش ویدیو
sudo apt install ffmpeg
```

### راه‌اندازی

```bash
# اجرای ربات
python3 run_bot.py

# یا استفاده از فایل اصلی
python3 bot.py
```

### تست

```bash
# اجرای تست‌ها
python3 test_bot.py
```

## ساختار پروژه

```
sootfun_bot/
├── bot.py              # فایل اصلی ربات
├── database.py         # مدل‌های دیتابیس
├── search_utils.py     # ابزارهای جستجو
├── admin_handlers.py   # هندلرهای پنل ادمین
├── media_utils.py      # ابزارهای پردازش رسانه
├── run_bot.py         # اسکریپت اجرای تولید
├── test_bot.py        # تست‌های خودکار
├── requirements.txt   # وابستگی‌ها
├── sootfun.db        # دیتابیس SQLite
├── downloads/        # پوشه دانلود ویدیوها
└── voices/           # پوشه ذخیره ویس‌ها
```

## استفاده

### برای کاربران عادی

1. شروع با دستور `/start`
2. اشتراک‌گذاری شماره تماس
3. استفاده از منوی اصلی یا جستجوی inline

### جستجوی Inline

در هر چت تایپ کنید:
```
@sootfun_bot کلمه کلیدی
```

### تبدیل ویدیو به ویس

1. انتخاب "تبدیل ویدیو به ویس" از منو
2. ارسال ویدیو
3. انتخاب بازه زمانی یا "تمام"

### برای ادمین

- دسترسی به پنل مدیریت با `/admin`
- افزودن/حذف ویس‌ها
- مشاهده آمار و درخواست‌ها

## عیب‌یابی

### مشکلات رایج

1. **خطای اتصال به تلگرام:**
   - بررسی اتصال اینترنت
   - تایید صحت توکن ربات

2. **خطای تبدیل ویدیو:**
   - بررسی نصب FFmpeg
   - بررسی فضای دیسک

3. **خطای دیتابیس:**
   - بررسی مجوزهای فایل
   - حذف `sootfun.db` و اجرای مجدد

### لاگ‌ها

لاگ‌های ربات در فایل `sootfun_bot.log` ذخیره می‌شوند.

## توسعه

### افزودن ویژگی جدید

1. ایجاد هندلر در `bot.py`
2. افزودن مدل دیتابیس در `database.py`
3. نوشتن تست در `test_bot.py`

### سفارشی‌سازی

- تغییر رنگ‌ها و استایل در `bot.py`
- تنظیم حساسیت جستجو در `search_utils.py`
- افزودن قابلیت‌های ادمین در `admin_handlers.py`
